Import / Export

L'export produit un fichier ZIP contenant products.json et le dossier images/. Copiez leur contenu dans le dossier public de votre site (à côté de boutique.js et boutique.css), en remplaçant les fichiers existants.

Le réglage « Prix saisis ci-dessous » n'a d'effet que si vous activez Stripe Tax côté serveur (voir README) — sinon les prix sont simplement facturés tels quels, sans calcul de taxe automatique.

Ajouter un produit

Laissez vide pour un produit sans quantité à gérer (ex : téléchargement, service).

Pour un produit téléchargeable : uploadez le fichier dans Vercel Blob (Storage > votre Blob store) et collez son URL ici. Un lien de téléchargement sécurisé sera envoyé par email après paiement (voir section 9 du README).

N'a d'effet que si les taxes automatiques (Stripe Tax) sont activées (section 7 du README). Sans effet si les taux de taxe manuels sont utilisés (section 7bis) — utilisez plutôt la case ci-dessous dans ce cas.

À cocher pour un livre imprimé si vous utilisez les taux de taxe manuels (TPS seule s'appliquera, pas de TVQ) — voir section 7bis du README.

Cochez le ou les sites où ce produit doit apparaître. Sur chaque site, le bloc d'intégration du widget doit porter l'attribut data-site-id correspondant (voir section 4 du README) pour que le filtrage fonctionne.

Stock en ligne (réapprovisionnement)

Une fois votre boutique déployée avec le suivi de stock activé (Vercel KV + variable ADMIN_STOCK_TOKEN, voir README), le stock affiché en ligne devient la vraie source de vérité — il se décompte à chaque vente. Le champ « Stock initial » ci-dessus ne sert qu'à l'amorcer la toute première fois qu'un produit est vendu. Pour l'ajuster ensuite (réassort, correction), utilisez ce panneau plutôt que de modifier « Stock initial ».
