Import / Export

L'export ZIP contient products.json et le dossier images/ — à copier dans le dossier public de votre site, en remplaçant les fichiers existants. L'export CSV est un format générique (SKU, code-barres, nom, prix, catégorie, stock) à essayer avec votre système de point de vente — vérifiez ses colonnes d'import attendues si l'import échoue, le format exact peut varier d'un système à l'autre.

Le réglage « Prix saisis ci-dessous » n'a d'effet que si vous activez Stripe Tax côté serveur (voir README) — sinon les prix sont simplement facturés tels quels, sans calcul de taxe automatique.

Stock en ligne (réapprovisionnement)

Une fois votre boutique déployée avec le suivi de stock activé (Vercel KV + variable ADMIN_STOCK_TOKEN, voir README), le stock affiché en ligne devient la vraie source de vérité — il se décompte à chaque vente. Le champ « Stock initial » ci-dessus ne sert qu'à l'amorcer la toute première fois qu'un produit est vendu. Pour l'ajuster ensuite (réassort, correction), utilisez ce panneau plutôt que de modifier « Stock initial ».
